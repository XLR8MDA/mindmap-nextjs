# MindMap AI

An AI-powered interactive mindmap generator built with Next.js. Type any topic and get a fully interactive, shareable mindmap in seconds — powered by Groq's LLaMA model.

![MindMap AI](https://img.shields.io/badge/Built%20with-Next.js%2015-black?style=flat-square&logo=next.js) ![Groq](https://img.shields.io/badge/AI-Groq%20LLaMA%203.3-orange?style=flat-square) ![Netlify](https://img.shields.io/badge/Deployed%20on-Netlify-00C7B7?style=flat-square&logo=netlify)

---

## Features

### Core
- **AI Mindmap Generation** — Enter any topic and get a structured, hierarchical mindmap generated by LLaMA 3.3 70B via Groq
- **Interactive Visualization** — Pan, zoom, and collapse/expand nodes using Markmap.js

### Resource Panel
- **Click any node** to instantly fetch 5 curated learning resources for that topic
- Resources include YouTube videos, Wikipedia articles, documentation, courses, and articles
- Resources are fetched with context of the root topic for more relevant results

### History
- **Browser-based history** — every generated mindmap is saved to `localStorage`
- Browse, restore, and delete past mindmaps from the history sidebar
- Persists across sessions with no account required, up to 50 entries

### Export & Sharing
- **Share link** — generates a compressed URL (`/share?d=...`) anyone can open to view your mindmap, no login required
- **Export PNG** — downloads the mindmap as a 2× retina-quality image
- **Export Markdown** — downloads the raw `.md` source file

## Getting Started

### Prerequisites
- Node.js 18+
- A [Groq API key](https://console.groq.com)

### Installation

```bash
git clone https://github.com/XLR8MDA/mindmap-nextjs.git
cd mindmap-nextjs
npm install
```

### Environment Setup

```bash
cp .env.local.example .env.local
```

Edit `.env.local`:
```env
GROQ_API_KEY=your_groq_api_key_here
```

### Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment (Netlify)

1. Push to GitHub
2. Connect repo on [Netlify](https://netlify.com) — build settings are auto-detected from `netlify.toml`
3. Add environment variable in **Site settings → Environment variables**:
   ```
   GROQ_API_KEY = your_groq_api_key_here
   ```
4. Deploy — API routes become Netlify Functions automatically

## How It Works

### Mindmap Generation
The `/api/generate-mindmap` route sends the user's query to Groq with a system prompt that instructs the model to respond using only nested markdown headings (`#`, `##`, `###`). Markmap.js transforms this into an interactive SVG tree.

### Resource Fetching
Clicking a node calls `/api/get-resources` with the node text and root topic as context. LLaMA returns titles, descriptions, and search queries. URLs are constructed programmatically — YouTube search URLs for videos, Wikipedia search for articles — guaranteeing no broken links.

### Share Links
The current mindmap markdown is compressed using `lz-string` and encoded into a URL query parameter (`/share?d=<compressed>`). No database or server state needed — the entire mindmap lives in the URL.
